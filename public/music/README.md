# Music

Six clips from each of the five instrument families in Kenney's CC0 "Music
Jingles" pack: `nes`, `hit`, `pizzi`, `sax`, `steel`.

These are stingers, not loops — the longest clip in the whole pack is 1.8
seconds, so looping one would be unlistenable. `music.ts` instead sequences
them: one family per tileset, a random clip every 1.7–3.9 seconds at low
volume with slight detune. Sparse spacing and no fixed order make it read as an
evolving bed rather than a ringtone, and it never repeats exactly.

The longest six clips per family were chosen, which is why the filenames are
renumbered rather than matching the pack's own.
